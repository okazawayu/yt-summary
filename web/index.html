端末間の同期

既読とお気に入りを、GitHub リポジトリの state ブランチに保存して、ブラウザとスマホで共有します。同期する端末それぞれで、同じトークンを一度だけ入力してください。

トークンの作り方
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → このリポジトリ
  3. Permissions：Contents を Read and write（他は不要）

トークンはこの端末のブラウザにだけ保存され、サイトには公開されません。
